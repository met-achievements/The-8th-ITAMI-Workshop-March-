# Christmas Memories — ARスノードーム試作

当日の写真を立体の写真立てに入れ、スノードームの中に雪を降らせるWebARです。
既存の伊丹ワークショップのファイルは変更せず、`christmas-snow-globe/` 以下だけで動きます。

## 開くページ

- `index.html`：写真を選んで3Dプレビュー。ドラッグ・左右矢印キーで回転。
- `ar.html`：カメラでHiroマーカーを認識して、同じドームをAR表示。
- `admin.html`：事前QR発行、A4印刷、写真登録ファイルの作成。
- `marker.html`：ARマーカーの表示・印刷。

公開URL：`https://met-achievements.github.io/The-8th-ITAMI-Workshop-March-/christmas-snow-globe/`

## 事前準備

1. **公開URLのスタッフ画面**で枚数と最初の受付番号を指定し、QRを発行します。
2. 「管理リストを保存」でJSONをスタッフ端末に保存します。これは復号鍵を含むため、公開リポジトリへ追加しません。
3. A4縦、倍率100%で印刷します。QRとARマーカーは異なる役割です。QRでページを開き、「ARで見る」を押して黒枠マーカーにかざします。
4. 管理リストを同じスタッフ画面で読み込めば、同じQRを再印刷できます。再発行ボタンで作り直すと別のQRになるため、印刷済みQRには元の管理リストを使います。

## 当日の写真登録

1. 渡すQRをスマホで開き、ページ下の「写真の登録」を押します。登録先が自動入力されます。
2. 対応する写真を選択して、受付番号・サムネイルを確認します。
3. 「① 登録ファイルを保存」で `<ランダムID>.json` をダウンロードします。
4. 「② GitHubにアップロード」で開くフォルダーに、そのJSONだけを追加してコミットします。GitHubへのログインと、このリポジトリへの書き込み権限が必要です。
5. GitHub Pagesの反映後、数分待って同じQRから確認します。未登録なら「写真を準備しています」と表示されます。
6. 差し替えは、同じQRから新しい登録ファイルを作り、同名JSONを置き換えます。QRの再印刷は不要です。

この試作版は**GitHubへの手動アップロード**です。「写真を選ぶ」だけでは他の端末から見られません。連続受付でのワンクリック登録は、認証付きの保存APIを追加する次段階です。

## 写真とQRの扱い

- 写真は端末で長辺1280px以下のJPEGに変換し、AES-256-GCMで暗号化します。EXIF等の元ファイルの付加情報はJPEG再生成で引き継ぎません。
- 写真データのIDは128bitのランダム値。鍵は256bitのランダム値で、QRのURLフラグメント `#k=...` に入れます。登録JSONには鍵を入れません。
- nonceは登録のたびに生成する96bit乱数。IDを追加認証データに使い、別IDへのファイルの取り違えも検出します。
- QRを持つ人は写真を開けます。本人確認・閲覧期限・QR流出時の失効機能はありません。参加者のQRや管理リストを公開しないでください。
- 公開リポジトリへ追加するのは暗号化済みの登録JSONだけです。元写真、管理リスト、鍵を含むURL一覧を追加しません。
- Gitの履歴には古い暗号化ファイルが残り得ます。この構成は厳密な削除期限を保証するものではありません。保存期限が必要な本番運用では認証付きストレージへ切り替えます。
- ホームの「写真を選んで試す」は、そのタブだけの一時プレビューです。サーバーへの送信は行いません。ARへの画面切り替えのため、縮小写真をsessionStorageに一時保存します。

## 動作条件と検証

- HTTPS、WebGL、Web Crypto API、カメラ利用許可が必要です。iPhoneはSafari、AndroidはChromeで実機確認してください。
- ARはマーカーを見失うと消えます。これは床や机を自動認識する方式ではありません。
- 雪は3D粒子200個。写真の前後に配置し、球の外にはみ出ないよう更新しています。
- OSの「視差効果を減らす」等が有効なら、初期状態で雪を停止します。3D画面の「雪を動かす」で手動再開できます。
- Three.js 0.164.1、A-Frame 1.4.0、AR.js 3.4.5を固定してCDNから読み込みます。回線制限がある会場では事前に読み込みを確認してください。
- 画像トラッキング、カメラ許可、印刷したマーカーのサイズは、会場の実機テストで確認が必要です。

テスト：リポジトリのチェックアウトで `node --test christmas-snow-globe/tests/tickets.test.mjs`。
静的サーバーで配信するだけで動き、ビルド工程はありません。ローカルプレビューで作ったQRはローカルURL用なので、本番の事前印刷は必ず公開URLから行ってください。
